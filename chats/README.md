# Chats Ordner

Hier werden alle Chat-Dateien gespeichert.

## Dateiarten

- **Automatische Speicherung**: `chat_[SessionID]_[Timestamp].json`
- **Manueller Export**: `manual_export_[SessionID]_[Datum].json` und `.txt`

## Hinweis

Da Browser-Sicherheit direkten Dateizugriff verhindert, werden Dateien zunächst in den Download-Ordner heruntergeladen. Verschieben Sie diese regelmäßig hierher für eine bessere Organisation.
